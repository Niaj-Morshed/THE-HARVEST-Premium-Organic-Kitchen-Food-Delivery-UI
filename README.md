🥗 THE HARVEST – Premium Organic Kitchen & Food Delivery UI
------------------------------------------------------------
Live Demo: https://niaj-morshed.github.io/THE-HARVEST-Premium-Organic-Kitchen-Food-Delivery-UI/


🚀 Overview:
-------------
THE HARVEST is a high-end, organic restaurant and food delivery interface designed to provide users with 
a fresh and cinematic dining experience. This project features dynamic menu filtering, an interactive
shopping cart, and a real-time search system, all wrapped in a sophisticated, nature-inspired aesthetic.


✨ Key Features:
-----------------
1. 🍽️ Smart Menu & Filtering
    * Dynamic Categories: Seamlessly filter food items by categories such as Appetizers, Main Course, Vegan, Desserts, and Drinks.
    * Animated Indicator: Features a smooth sliding indicator that tracks menu transitions for a premium feel.

2. 🛒 Fully Functional Cart System
    * Real-time Updates: Add items, adjust quantities, and view automatic total price calculations instantly.
    * Side Panel UI: Manage cart items through a premium sliding drawer interface.
    * Data Persistence: Integrated with LocalStorage to ensure cart data remains intact even after a page refresh.

3. ❤️ Interactive Favorites (Wishlist)
    * Save for Later: Users can save their favorite dishes by clicking the heart icon, stored in a dedicated panel.
    * Persistence: Favorite items are saved locally, ensuring they are available across browsing sessions.

4. 🔍 Smart Live Search
    * Instant Suggestions: Real-time search dropdown that suggests food items as the user types.
    * Quick Filter: Clicking a suggestion instantly filters the menu to show the selected item.

5. 🌙 Advanced Theme Switcher
    * Dark & Light Mode: Toggle between an elegant dark theme and a fresh light theme for optimal viewing.
    * Persistent Theme: The user's theme preference is saved in the browser for future visits.

6. ⚡ Modern Skeleton Loading
    * Shimmer Effect: Implements a professional "Skeleton" loading state to improve perceived performance and user experience while data loads.

7. 🔔 Premium Toast Notifications
    * Animated Alerts: Beautifully animated toast messages provide feedback for actions like "Added to Cart," "Removed from Wishlist," or "Order Confirmed".

8. 📝 Interactive Table Reservation
    * Booking System: A clean, validated reservation form allows users to request table bookings directly through the UI.



🛠️ Technologies Used:
----------------------
1. Core Stack
    * HTML5: Semantic structure for better SEO and accessibility.
    * CSS3 (Modern UI): Advanced styling using CSS Variables, Grid, Flexbox, and custom Keyframe animations.
    * JavaScript (ES6+): Powering the core logic, DOM manipulation, and LocalStorage management.

2. External Assets
    * Google Fonts: Utilizing 'Cormorant Garamond' and 'Montserrat' for a luxury typographic experience.
    * Font Awesome: Integrated icon library for an intuitive and professional interface.

📲 Fully Responsive Architecture:
    * Mobile Optimized: Expertly crafted to provide an app-like experience on small screens.
    * Touch Friendly: Features floating controls and sliding panels optimized for mobile interaction.
